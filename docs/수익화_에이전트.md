# 수익화 에이전트 (쿠팡 파트너스 제휴 · 댓글→DM 링크)

Meta/Instagram 정책 안에서만 동작한다. 팔로우·좋아요 봇, 먼저 보내는 DM, 스크래핑은 하지 않는다.

## 1. 쿠팡 파트너스 제휴

- 흐름: 시안 생성 → **미리보기**에서 "쿠팡 파트너스 제휴 링크" 켜기 → 키워드(분석의 주제·해시태그에서 자동 제안)로 **상품 추천** → 하나 선택(또는 링크 직접 붙여 넣기) → 승인.
- 제휴를 켜고 링크를 고르지 않으면 승인(게시)이 막힌다.
- 링크가 붙으면 게시 직전에 캡션 **맨 앞**에 공정위 고지 문구가 자동으로 들어간다. 문구는 `config.yaml` 의 `monetize.disclosure_text` 에서 바꿀 수 있지만 비우거나 위치를 옮길 수 없다(비우면 기본 문구, 본문에 있으면 맨 앞으로 이동).
- 인스타 캡션의 링크는 눌리지 않으므로 CTA("댓글에 '링크' 남기면 DM으로 보내드려요")를 넣고, 2번 기능으로 DM을 보낸다.
- 글자 수는 공백 포함 2200자 한도. 넘치면 해시태그(뒤에서부터) → 본문 순으로 줄이고, 고지 문구와 CTA는 자르지 않는다.
- 키: `.env` 의 `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY`, `COUPANG_SUB_ID`(선택). 키가 없으면 파트너스 사이트에서 만든 링크를 직접 붙여 넣는다.
- 쿠팡 검색 API는 호출 한도가 낮다. 같은 키워드 결과는 `coupang_cache_minutes`(기본 60분) 동안 재사용한다.

### 사용자가 해야 할 일 (쿠팡)
1. 쿠팡 파트너스 가입 → 활동 채널(인스타그램 계정) 등록.
2. 최종 승인(누적 판매 기준 충족 후 심사) 뒤에 Open API 키 발급 가능. 승인 전에는 "링크 직접 붙여 넣기"로 사용.
3. 게시물마다 고지 문구가 들어가는지 미리보기에서 확인.

## 2. 댓글 → DM 링크 자동 응답

- 대상: 게시 완료 + 제휴 링크가 있는 게시물. **전체 스위치**(수익화 화면, 기본 꺼짐) + **게시물별 스위치**(기본 켜짐)가 모두 켜져야 동작.
- 댓글에 키워드(기본: 링크, link, 정보 — 게시물별로 바꿀 수 있음)가 있으면 그 댓글 작성자에게만 **비공개 답장(Private Reply) 1회**. 선택적으로 공개 답글 "DM 보냈어요!".
- 강제 규칙: 댓글당 1회(처리 기록은 `data/monetize/comment_dm_state.json`, 실패해도 재시도 안 함) · 댓글 후 7일 이내 · 내 계정 댓글 제외 · 시간당 최대 DM(기본 200, 상한 500 — Meta 한도 750/시간보다 낮게) + 발송 간 최소 3초 · 수신자는 항상 `recipient.comment_id` 이므로 댓글을 달지 않은 사람에게는 보낼 수 없다.
- 기록: `data/monetize/comment_dm_log.jsonl` (키워드 매치 댓글, 보냄/건너뜀/오류와 사유). 토큰·키는 기록하지 않는다. PWA '수익화' 화면에서 본다.

### 수신 방식
- **폴링(기본)**: API 서버(`npm run api`)가 켜져 있는 동안 `poll_interval_seconds`(기본 120초)마다 최근 제휴 게시물의 댓글을 조회. 공개 HTTPS 주소가 필요 없다. 게시물당 최근 50개 댓글만 본다.
- **웹훅(선택)**: 공개 HTTPS 주소가 있을 때 Meta 앱 → Webhooks → Instagram → `comments` 필드 구독.
  - 콜백 URL: `https://<공개주소>/api/monetize/webhook/instagram`
  - 확인 토큰: `.env` 의 `META_WEBHOOK_VERIFY_TOKEN`
  - POST 는 `X-Hub-Signature-256` 을 `FB_APP_SECRET` 로 검증, 틀리면 403.

### API 방식
- 기본 `messaging_api: facebook_login` (이 프로젝트의 토큰 방식: Facebook 로그인 + 페이지에 연결된 IG 비즈니스 계정).
  - 비공개 답장: `POST https://graph.facebook.com/v22.0/{PAGE_ID}/messages` + **페이지 액세스 토큰**, body `{"recipient":{"comment_id":...},"message":{"text":...}}`.
  - `FB_PAGE_ID`/`FB_PAGE_ACCESS_TOKEN` 이 없으면 `IG_ACCESS_TOKEN` 으로 `/me/accounts` 에서 IG 계정에 연결된 페이지 토큰을 찾는다.
- `instagram_login`: Instagram 로그인 토큰을 쓰는 경우 `POST https://graph.instagram.com/v22.0/{IG_USER_ID}/messages`.

### 필요한 권한 (Meta 앱 검수)
Facebook 로그인 방식(기본):
- `instagram_basic`, `instagram_manage_comments` (댓글 읽기·공개 답글)
- `instagram_manage_messages` (Instagram 메시지), `pages_messaging` (비공개 답장 문서에 명시)
- `pages_show_list`, `pages_read_engagement`, `pages_manage_metadata` (페이지 토큰·웹훅 구독)
- 기존 게시용: `instagram_content_publish`

Instagram 로그인 방식: `instagram_business_basic`, `instagram_business_manage_comments`, `instagram_business_manage_messages`.

### 사용자가 해야 할 일 (Meta)
1. IG 계정을 비즈니스/크리에이터로, Facebook 페이지에 연결.
2. 인스타그램 앱 → 설정 → 메시지 → 연결된 도구 → **메시지 접근 허용** 켜기.
3. Meta 앱에 Messenger(Instagram 메시지) 제품 추가, 위 권한 요청.
4. 본인(앱 역할이 있는 계정) 외 일반 사용자에게 보내려면 **고급 액세스(Advanced Access) + 앱 검수(App Review) + 비즈니스 인증**이 필요. 검수 전(Standard Access)에는 앱 역할이 있는 사람의 댓글에만 동작.
5. 검수용 시연 영상: 댓글 → 비공개 답장 1회 → 로그 화면.

> 확인 필요: 권한 이름·한도는 Meta 문서가 자주 바뀐다. 검수 신청 전에 developers.facebook.com 의 Instagram Private Replies / Rate Limits 문서로 다시 확인할 것.

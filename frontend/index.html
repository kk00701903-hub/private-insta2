댓글 → DM 자동 응답

규칙: 댓글당 1회 · 댓글 후 7일 이내 · 내 계정 댓글 제외 · 댓글 안 단 사람에게는 절대 보내지 않음.

    제휴 게시물

    기록

    시각결과계정댓글키워드사유

    설정

    키는 이 PC의 .env에만 저장됩니다. 코드에 넣지 마세요.

    연결 상태

      .env · Kling CLI 안내
      1. CLAUDE_API_KEY — 사진·코멘트 분석
      2. IG_USER_ID / IG_ACCESS_TOKEN — Graph API 게시
      3. IMGBB_API_KEY 또는 PUBLIC_BASE_URL — 캐러셀 공개 URL
      4. Kling 일러스트: 터미널에서 npm run kling:login (브라우저 OAuth). 또는 KLING_API_KEY
      5. KLING_BACKEND=auto|cli|api — 기본 auto (CLI 우선)

      홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

      API 키가 필요합니다

      Claude 키가 없으면 오프라인 분석으로 테스트할 수 있습니다. 게시는 IG 토큰이 필요합니다.
